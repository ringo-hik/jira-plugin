# Simple JIRA Plugin for VSCode

## ✅ 완전히 단순화된 JIRA 확장

이 확장은 사용자 관점에서 **최대한 단순하게** 설계되었습니다.

### 🎯 핵심 기능

- **3가지 설정만**: JIRA URL, 사용자 ID, PAT 토큰
- **자동 프로젝트 선택**: 사용 가능한 프로젝트 목록 자동 표시
- **이슈 목록**: 선택한 프로젝트의 최신 이슈 20개 표시
- **원클릭 열기**: 이슈 클릭으로 브라우저에서 바로 열기

### 🚀 사용법

1. **확장 활성화**: VSCode 재시작 또는 F5로 디버깅 모드 실행
2. **연결 설정**: "Setup JIRA Connection" 클릭 또는 명령 팔레트에서 실행
3. **정보 입력**:
   - JIRA 서버 URL (예: `https://your-company.atlassian.net`)
   - 사용자 ID
   - Personal Access Token (PAT)
4. **프로젝트 선택**: 자동으로 표시되는 프로젝트 목록에서 선택
5. **이슈 확인**: 사이드바 JIRA 탭에서 이슈 목록 확인

### 📋 지원 기능

- ✅ JIRA Server 연결 (PAT 인증)
- ✅ 프로젝트 목록 자동 로드
- ✅ 이슈 목록 표시 (최신순)
- ✅ 브라우저에서 이슈 열기
- ✅ 실시간 연결 상태 표시
- ✅ 자동 재연결
- ✅ 오류 처리 및 사용자 알림

### 🛠️ 개발 및 빌드

```bash
# 컴파일
npm run compile

# 디버깅 모드 실행
F5 키 또는 Debug > Start Debugging

# VSIX 패키지 생성 (옵션)
vsce package
```

### 🔧 기술적 특징

- **최소 의존성**: jira-connector만 사용
- **타입스크립트**: 완전한 타입 안전성
- **단일 파일 구조**: extension.ts + jira.service.ts
- **메모리 효율적**: 불필요한 기능 제거
- **빠른 로딩**: 최적화된 활성화

### 🎨 UI/UX 특징

- **직관적 TreeView**: 프로젝트 → 이슈 계층 구조
- **상태 표시**: 연결 상태 및 진행 상황 실시간 표시
- **컨텍스트 메뉴**: 우클릭으로 추가 기능 접근
- **아이콘**: 이슈 상태별 구분된 아이콘
- **툴팁**: 이슈 상세 정보 미리보기

### 🚨 주의사항

- JIRA Cloud가 아닌 **JIRA Server**만 지원
- Personal Access Token (PAT) 필요
- 네트워크 연결 필요

### 🆚 기존 버전과 차이점

| 기능 | 기존 버전 | 단순화 버전 |
|------|-----------|-------------|
| 설정 옵션 | 40개+ | 3개 |
| 설정 방법 | 복잡한 설정 UI | 간단한 입력 대화상자 |
| 필수 입력 | 많은 옵션들 | URL + 사용자명 + PAT만 |
| 프로젝트 선택 | 수동 설정 | 자동 목록 표시 |
| 이슈 표시 | 복잡한 필터링 | 단순한 최신순 목록 |
| 코드 복잡도 | 높음 | 매우 낮음 |

이제 사용자는 단 3가지 정보만 입력하면 즉시 JIRA를 사용할 수 있습니다! 🎉
